---
name: Segmentos de gestão por empresa
description: Valores de "Gestão" por empresa e projetos visíveis em cada segmento
type: feature
---
A gestão é definida por usuário **por empresa** (tabela `user_management_segments`; fallback global em `sap_user_directory.management_segment`). O mesmo usuário pode ter gestão diferente em cada empresa.

- ANA Gaming: ANA Gaming → projeto 7K; Lótus → VERA + CASSINO; CSC → todos os projetos.
- Open Gaming: CSC → todos; BET.BET → BET.BET; DONALD → DONALD.
- Cactus Tecnologia (SBO_CACTUS), Instituto (SBO_INSTITUTO_ANA) e Cactus Providers (cactus_providers): apenas CSC → todos os projetos.
